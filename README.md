# 🌴 Parallax Islands

A modern and interactive **Parallax Website** built with HTML, CSS, and JavaScript.

This project creates a layered parallax hero section where different image layers move at different speeds while scrolling, creating a smooth and immersive depth effect.

---

## ✨ Features

- 🌴 Modern parallax website design
- 🖼️ Multi-layer image animation
- 🌀 Different movement speeds for each layer
- 📜 Smooth scroll-based animations
- ✨ Animated Welcome title
- 📱 Responsive design
- 🎨 Modern and minimal UI
- ☰ Interactive sidebar menu
- ❌ Close button for sidebar
- 🔗 Navigation links
- ⚡ Optimized scroll animation using `requestAnimationFrame`

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- CSS Positioning
- CSS Transform
- `requestAnimationFrame()`
